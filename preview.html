// Two-layer MLP on MNIST — full working example
package main

import (
    "github.com/gomlx/gomlx/graph"
    "github.com/gomlx/gomlx/ml/layers"
    "github.com/gomlx/gomlx/ml/train"
)

// modelGraph defines your model as a pure function.
// GoMLX traces it once, compiles to XLA, runs fast.
func modelGraph(ctx *context.Context, spec any, inputs []*graph.Node) []*graph.Node {
    x := inputs[0]                                  // [batch, 784]
    x  = layers.Dense(ctx.In("hidden"), x, true, 128) // → [batch, 128]
    x  = graph.Relu(x)
    x  = layers.Dense(ctx.In("output"), x, true, 10)  // → [batch, 10]
    return []*graph.Node{x}
}
// Build a trainer with loss, optimizer, and eval callbacks
trainer := train.NewTrainer(manager, ctx, modelGraph,
    losses.SparseCategoricalCrossEntropyLogits,
    optimizers.Adam(),
    train.EveryNSteps(100, plotMetricsFn),
    train.NanLogger(),
)

// Loop runs entirely on-device — no Python round-trips
loop := train.NewLoop(trainer)
loop.RunSteps(trainDS, 10_000)

// Evaluate on test set
metrics := trainer.Eval(testDS)
fmt.Printf("Test accuracy: %.2f%%\n", metrics["accuracy"]*100)
// Graphs are compiled functions — define once, run anywhere
manager := backends.New() // auto-selects GPU > CPU

computeFn := graph.Compile(manager, func(g *graph.Graph) *graph.Node {
    x := graph.Parameter(g, "x", shapes.Make(dtypes.Float32, 3))
    w := graph.Const(g, []float32{1, 2, 3})
    return graph.ReduceSum(graph.Mul(x, w), 0)
})

result := computeFn.Call(xTensor)
fmt.Println(result) // Tensor[float32: scalar] = 14
Why GoMLX

Everything you need.
Nothing you don't.

XLA acceleration

Compile your model graph once to XLA. The same Go code runs on CPU, NVIDIA GPU, and Google TPU without modification. Full JIT compilation and kernel fusion built in.

Learn about backends →

Static typing, caught at compile time

Go's type system catches shape mismatches before your first training step. No more cryptic runtime crashes three epochs into a run. Tensor shapes are first-class citizens.

Explore the type system →

Pure Go

One go get, no virtual environments, no Python runtime, no version conflicts. Idiomatic Go that your whole team already knows.

Rich layers API

Dense, Conv, Attention, BatchNorm, Dropout, Embeddings — composable, easy to extend with custom layers.

Live plotting

Built-in Gonb/Jupyter integration plots training metrics in real time. Loss curves, accuracy, custom metrics — all without leaving Go.

Modular design

Swap backends, optimizers, and data pipelines independently. Use just the graph layer, or the full training stack — your choice.

Installation

Get GoMLX running in your Go project in under five minutes.

Requirements

Before installing GoMLX, make sure you have the following:

  • Go 1.21 or later — GoMLX uses generics and newer standard library features
  • A C compiler (gcc or clang) — required to build the XLA bindings
  • Optional: CUDA 12+ — for NVIDIA GPU acceleration

You can verify your Go version with:

go version
# go version go1.21.5 linux/amd64

Install via go get

GoMLX is a standard Go module. Add it to your project with:

go get github.com/gomlx/gomlx@latest

💡 On Linux, the XLA shared library is downloaded as a pre-built binary. On macOS, it is compiled from source. If you see a long compile step on first build, this is expected and cached afterward.

Verify the installation

Create a main.go and paste this:

package main

import (
    "fmt"
    "github.com/gomlx/gomlx/backends"
    "github.com/gomlx/gomlx/graph"
)

func main() {
    manager := backends.New()
    result := graph.Compile(manager, func(g *graph.Graph) *graph.Node {
        a := graph.Const(g, []float32{1, 2, 3})
        b := graph.Const(g, []float32{4, 5, 6})
        return graph.Add(a, b)
    }).Call()
    fmt.Println(result) // Tensor[float32: 3] = [5 7 9]
}

Run it with go run main.go. If you see Tensor[float32: 3] = [5 7 9], GoMLX is installed and working correctly.

GPU support (NVIDIA)

To enable GPU acceleration, install the CUDA backend and import it as a side-effect:

go get github.com/gomlx/gomlx/backends/cuda@latest
import (
    _ "github.com/gomlx/gomlx/backends/cuda"
    "github.com/gomlx/gomlx/backends"
)

manager := backends.New() // automatically uses GPU if available

📝 GoMLX selects the best available backend automatically: GPU › CPU. Force a specific backend with backends.NewWithName("cpu").

Troubleshooting

cgo: C compiler not found — Install gcc: sudo apt install build-essential (Ubuntu) or xcode-select --install (macOS).

Build is very slow on first run — This is normal. XLA is being compiled. Subsequent builds use the cache and are fast.
